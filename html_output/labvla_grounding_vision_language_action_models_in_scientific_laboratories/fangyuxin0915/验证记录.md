# 自动检查记录

当前版本为包含最新动画修正的封面与六章、九个主要交互模块的项目。

- TypeScript 与 Vite 构建检查。
- 桌面、平板、手机布局、资源加载和主要交互检查。
- 完整操作流程的连续帧检查，确认目标可达且肘部路径连续。
- 流匹配推理的像素比较，确认当前观测不变、动作候选发生变化。
- 播放、暂停、拖动进度、逐步查看及减少动态效果行为检查。
- UTF-8 和异常字符检查。

投稿前将继续运行仓库的 validate、catalog、validate:pr、build:paper 与差异范围检查。人工内容核验和最终网页确认由贡献者完成，结果记录在 Pull Request 中。

投稿适配将原讨论页拆为能力定位与研究局限两章，并采用仓库识别的组件注册形式；全部动画实现保留最新版本。
